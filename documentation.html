Multi Script Editor Documentation

General Overview

Multi Script Editor is an open-source, cross-platform, and cross-application Python editor. It can be run as a standalone application or embedded within other software applications (such as Houdini, Nuke, Maya, 3DsMax), offering the ability to script in Python efficiently and centrally.

Key Features:

  • Preserves and loads tabs and the code within them.
  • Interactive execution of selected code.
  • Adjustable color themes for the code editor.
  • Code completion (via the jedi module).
  • Context completion for different functions, such as existing nodes and scene paths depending on the integrated software.

Options by Menu

Below is a breakdown of the different actions and tools grouped by the menu where they are located within the application:

File Menu

  • Open ScriptCTRL + O: Opens an existing Python script file.
  • Save ScriptCTRL + S: Saves the script in the current tab.
  • Save SessionCTRL + SHIFT + S: Saves the current session, including open tabs and their contents.
  • Close All Tabs: Closes all open tabs, leaving only one empty tab (prompts for confirmation before closing).
  • QuitCTRL + Q: Closes the application.

Edit Menu (Tools)

  • UndoCTRL + Z: Undoes the last action.
  • RedoCTRL + Y: Redoes the previously undone action.
  • CopyCTRL + C: Copies the selected text to the clipboard.
  • CutCTRL + X: Cuts the selected text to the clipboard.
  • PasteCTRL + V: Pastes the clipboard content.
  • Delete LineCTRL + D: Deletes the line where the cursor is currently located.
  • Duplicate LineCTRL + SHIFT + D: Duplicates the current line or selected text.
  • Move Line(s) UpALT + UP: Moves the selected line(s) one position up.
  • Move Line(s) DownALT + DOWN: Moves the selected line(s) one position down.
  • Add QuotesALT + Q: Adds quotes around the selected text.
  • CommentALT + C: Comments or uncomments the current line or selected text block.
  • Select Next OccurrenceCTRL + ALT + D: Selects the next occurrence of the current word.
  • Select All OccurrencesCTRL + SHIFT + ALT + D: Selects all occurrences of the current word.
  • Find and ReplaceCTRL + F: Opens the tool to find and replace text within the editor.
  • Tab to spaces: Converts tabs in the document to spaces.
  • Render WhitespaceCTRL + SHIFT + W: Shows or hides whitespace characters in the editor.
  • Word WrapALT + W: Toggles automatic word wrap in the code editor.
  • Word Wrap (Output)CTRL + ALT + W: Toggles word wrap in the output console.

Run Menu

  • Clear Output before ExecutionCTRL + ALT + C: If enabled, clears the output console before each execution.
  • Clear OutputCTRL + SHIFT + C: Manually clears the output console.
  • dir()ALT + D: Executes the dir() function on the current word and displays the result in the output.
  • help()ALT + H: Executes the help() function on the current word and displays the documentation.
  • print(): Adds a print() statement for the selected word.
  • type()ALT + T: Executes the type() function on the current word to display its data type.
  • Echo Executed CommandALT + E: Displays the executed code in the output console before the results.
  • Execute AllALT + ENTER: Executes all the code in the current tab.
  • Execute LineCTRL + ALT + ENTER: Executes only the line of code where the cursor is located.
  • Execute SelectedCTRL + ENTER: Executes only the currently selected text block.

Options Menu

  • AutocompleteALT + A: Toggles the basic autocomplete function.
  • Fuzzy Autocomplete: Enables fuzzy search for autocompletion.
  • Show Docstrings: Shows or hides docstrings during autocompletion.
  • Show OutlineCTRL + SHIFT + O: Shows or hides the code outline panel (classes and functions).
  • Syntax Check: Toggles real-time syntax checking.
  • Always on topCTRL + ALT + T: Keeps the editor window always visible on top of other windows.
  • Choose Font...CTRL + MouseWheel: Allows changing the font type and size of the editor text.
  • Open Settings Folder: Opens the folder where the editor's configuration and session files are saved.
  • Theme: Submenu that allows opening the theme editor (Edit...) to customize the interface colors.

Help Menu

  • Quick HelpF1: Displays a quick help guide on general usage and variables.
  • GitHub: Opens the project repository page on GitHub (Manual).
  • Houdini Env Variables: Opens Houdini environment variables documentation.
  • Houdini hou package: Opens documentation for the Houdini hou module.
  • Maya Commands: Opens Maya commands documentation.
  • Nuke Dev Guide: Opens the Nuke development guide.
  • Qt for Python: Opens the official Qt for Python (PySide) documentation.
  • Qt Modules: Opens documentation for Qt modules.
  • Python documentation: Opens the official Python documentation for the current version.
  • Shortcuts: Displays the full list of keyboard shortcuts for the editor.
  • Documentation: Opens this documentation file.
  • Help: Displays general help information for the editor.
  • About: Displays information about the application's version and authors.
