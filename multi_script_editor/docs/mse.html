Multi Script Editor Documentation

General Overview

Multi Script Editor is an open-source, cross-platform, and cross-application code editor. It can be run as a standalone application or embedded within other software applications (Houdini, Maya, Nuke), offering the ability to edit and execute code efficiently and centrally while automatically adapting to the host application's environment. While optimized for Python, it supports syntax highlighting, file parsing, and outline navigation for a wide range of web and CGI-centric file formats.

Key Features:

  • Preserves and loads tabs and the code within them automatically across sessions.
  • Interactive execution of selected code blocks, single lines, or entire scripts (for Python files).
  • Fully adjustable and customizable color themes for the code editor and UI.
  • Advanced code completion (powered by the jedi module) and docstring visualizers for Python.
  • Multi-format syntax highlighting and editing support for Python, JavaScript, HTML, YAML, Markdown, CSS, Text, Log, USD, and JSON.
  • Smart document structure outline and symbol parsing (supports Python classes/functions, JSON/YAML keys, and USD def/class/over declarations).
  • Context-aware completion for different functions, such as existing nodes and scene paths depending on the integrated host software.
  • Built-in syntax checking and multi-cursor editing support.
  • Code snippets functionality for quickly inserting predefined blocks of code.

Options by Menu

Below is a detailed breakdown of the different actions and tools grouped by the menu where they are located within the application, utilizing sentence case for ease of use:

File Menu

  • Open scriptCTRL + O Opens an existing Python script file from your local filesystem, loading its contents into a new tab in the editor for editing and execution.
  • Save scriptCTRL + S Saves the script in the currently active tab. If the script is new and hasn't been saved yet, it will prompt for a destination file path.
  • Save script asCTRL + SHIFT + S Saves the script in the currently active tab to a new file and opens it in a new separate tab.
  • Save sessionCTRL + ALT + S Forces a save of the entire current session state. This includes all open tabs, their contents, specific order, bookmarks, and code folding states, ensuring they are automatically restored the next time the editor is launched.
  • Recent filesCTRL + P A sub-menu containing recently opened files. Pressing the shortcut opens a search popup palette to quickly filter and open recent files, or remove them from the list.
  • Save output A sub-menu containing options to save the text in the output panel:
    • As...: Saves the output panel text to an external file.
    • To tab: Copies all text in the output panel into a new editor tab.
  • Sessions A sub-menu to manage and restore your editor workspaces:
    • Save session...: Saves the current active tabs and their arrangement as a named session.
    • Restore backup...: Restores a session backup file.
    • Delete session: A sub-menu to permanently delete a saved session.
    • List of saved sessions: Lists your saved sessions; clicking one restores all its tabs.
  • Snippets A sub-menu containing tools to manage custom code snippets. Built-in default snippets are protected from deletion:
    • Insert/save snippetALT + S: Opens a dialog to insert a predefined snippet at the current cursor position, or save the currently selected text as a new snippet. Pressing Numpad Enter on a highlighted snippet in the insertion list executes it directly in the console.
    • Import / Export: Import snippet collections from JSON files or export them for backup.
    • Delete snippet: Allows removing custom snippets.
  • Close all tabs Closes all open tabs to reset your workspace, leaving only one empty tab. It prompts for confirmation to prevent accidental loss of unsaved snippets.
  • QuitCTRL + Q Closes the application safely. It ensures that the current session state is preserved before exiting.

Tab Interactions & Context Menu

  • Middle-click Closes the tab directly under the mouse cursor.
  • Duplicate Tab Creates a copy of the current tab with the same text.
  • Double-click / Rename TabALT + R Triggers an inline text editor directly on the tab label to rename it. Press Enter to confirm or Escape to cancel. Tab labels now display the full file name.
  • Copy File PathALT + SHIFT + C Copies the absolute file path of the currently active tab (if it represents a saved file) to the system clipboard.

Bookmarks Menu

  • Toggle BookmarkCTRL + F2 Toggles a bookmark on the current cursor line. A colored ribbon tag is displayed in the gutter. A semi-transparent hover preview is also shown when hovering over the gutter.
  • Next BookmarkF2 Navigates the cursor to the next bookmark in the active document, centering the viewport on the line.
  • Previous BookmarkSHIFT + F2 Navigates the cursor to the previous bookmark in the active document, centering the viewport on the line.
  • Clear BookmarksCTRL + SHIFT + F2 Removes all bookmarks from the current active document. A confirmation dialog is displayed first to prevent accidental clearing.
  • Go to bookmark...CTRL + B Opens a search popup palette to filter and jump to bookmarked lines in the current editor file.

Edit Menu

  • UndoCTRL + Z Reverts the last text editing action in the active script, allowing you to step backward through your recent changes.
  • RedoCTRL + Y Re-applies the last undone action, allowing you to step forward through changes you previously undid.
  • Clipboard managerCTRL + SHIFT + V Opens a history widget displaying previously copied and cut code blocks. Selecting an item inserts it at the cursor, and pressing Delete on an entry removes it. History is persisted across sessions.
  • CopyCTRL + C Copies the currently selected text to the system clipboard for pasting elsewhere.
  • CutCTRL + X Removes the currently selected text from the document and places it into the system clipboard.
  • PasteCTRL + V Inserts the current content of the system clipboard at the cursor's location.
  • Add quotesALT + Q Wraps the currently selected text with quotation marks. Very useful for quickly converting variables or text into string literals.
  • CommentALT + C Toggles the Python comment state (using #) for the current line or selected block of lines, allowing you to quickly comment out or uncomment code blocks.
  • f-stringALT + F Converts the selected text or the word under the cursor into a Python f-string literal.
  • Delete line(s)CTRL + D Immediately deletes the current line or all lines spanned by the current selection.
  • Duplicate line(s)CTRL + SHIFT + D Duplicates the current line or the selected text block, inserting it immediately below the original.
  • Move line(s) upALT + UP Shifts the currently selected line(s) or the line at the cursor one position upwards in the document.
  • Move line(s) downALT + DOWN Shifts the currently selected line(s) or the line at the cursor one position downwards in the document.
  • Add Cursors to line endsALT + SHIFT + I Adds a cursor at the end of each selected line, allowing you to edit the ends of multiple lines simultaneously.
  • Add cursor aboveCTRL + ALT + UP Adds a cursor on the line immediately above the current selection or topmost cursor, facilitating multi-cursor editing.
  • Add cursor belowCTRL + ALT + DOWN Adds a cursor on the line immediately below the current selection or bottommost cursor, facilitating multi-cursor editing.
  • Next highlight/selectionCTRL + J Moves the focus to the next highlighted occurrence or selection.
  • Previous highlight/selectionCTRL + SHIFT + J Moves the focus to the previous highlighted occurrence or selection.
  • Select next occurrenceCTRL + ALT + D Finds and selects the next instance of the currently selected word (or the word under the cursor), enabling multi-cursor editing for rapid refactoring.
  • Select all occurrencesCTRL + SHIFT + ALT + D Selects every instance of the current word throughout the entire document, placing a cursor at each instance for simultaneous editing.
  • Find and replaceCTRL + F Opens the search tool panel to find specific text strings and optionally replace them with new text. It supports case sensitivity and regular expressions.
  • Go to lineCTRL + G Opens a modern popup palette with a list of lines (including syntax-highlighted previews) to filter and jump to a specific line in the editor, centering the cursor vertically in the viewport.
  • Go to symbolCTRL + R Opens a quick navigation palette to fuzzy-search and jump to symbols (functions, classes) in the current editor file. Automatically clears the outline view if syntax errors are detected.
  • Tab to spaces Converts all tab characters in the current document to standard space characters (typically 4 spaces) to ensure PEP 8 compliance and avoid indentation errors.
  • Spaces to tab Converts groups of 4 spaces into standard tab characters in the current document to meet format requirements.
  • Trim trailing whitespaceALT + SHIFT + W Trims trailing spaces and tab characters from the ends of all lines in the active document immediately.
  • Show autocompletionCTRL + SPACE Manually triggers the autocomplete suggestions popup list at the current cursor position.
  • Highlight all occurrences Toggles automatic visual highlighting of all matching occurrences of the selected word throughout the active document.
  • Occurrences are case sensitive Toggles case sensitivity for matching word occurrences highlighted in the document.
  • Prefer single quotes Toggles quote preference to single quotes instead of double quotes when using 'Add quotes' and f-string utilities.
  • Trim auto whitespace Toggles automatic trimming of trailing whitespace whenever you save a script.
  • Render whitespaceCTRL + SHIFT + W Toggles the visibility of whitespace characters (spaces as dots, tabs as arrows) in the editor to aid in formatting and detecting trailing spaces.
  • Word wrapALT + W Toggles automatic wrapping of long lines of code so they visually fit within the editor's width without requiring horizontal scrolling.
  • Word wrap (output)CTRL + ALT + W Toggles word wrap specifically for the output console panel, preventing horizontal scrolling for long print outputs.

View Menu

  • Code OutlineCTRL + SHIFT + O Toggles the visibility of the code outline sidebar. This panel provides a structural overview of the script (showing classes, methods, and functions) for rapid navigation.
  • Code outline button Toggles the visibility of the outline toggle button in the tab bar.
  • MenusCTRL + M Toggles the visibility of the main window menu bar. If the menu bar is hidden, a hamburger menu button dynamically appears in the toolbar to retain access to all menu options.
  • ToolbarCTRL + ALT + T Toggles the visibility of the editor toolbar above the tab bar. Toolbar visibility status is persisted across sessions.
  • OutputCTRL + K Toggles the visibility of the output console panel.
  • Output at the bottomCTRL + U Toggles the layout position of the output console, placing it at the bottom of the window when checked.
  • FoldALT + - Folds the current code block at the cursor's location.
  • UnfoldALT + + Unfolds the current code block at the cursor's location.
  • Fold allALT + SHIFT + - Folds all collapsible code blocks in the current document.
  • Unfold allALT + SHIFT + + Unfolds all collapsed code blocks in the current document.
  • Zoom inCTRL + + Increases the editor font size globally.
  • Zoom outCTRL + - Decreases the editor font size globally.
  • Reset zoomCTRL + 0 Resets the editor font size to the theme's default size.

Run Menu

Note: Execution features (including code execution and Python helper queries like type, help, dir, and print) are exclusively supported for Python documents. They are automatically disabled and inactive when editing non-Python files (e.g. JSON, HTML, YAML, CSS).

  • Clear output before executionCTRL + ALT + C When enabled, the application automatically clears the console output panel every time you run a script, keeping the output focused exclusively on the latest execution results.
  • Clear outputCTRL + SHIFT + C Manually clears all text currently displayed in the output console panel.
  • dir()ALT + D Wraps the word under the cursor with the Python dir() function and executes it. This prints all valid attributes and methods of the selected object in the output console.
  • help()ALT + H Wraps the word under the cursor with the Python help() function and executes it, displaying Python's built-in documentation for that specific object or function.
  • print()ALT + E Wraps the word under the cursor in a print() statement, making it easy to quickly output a variable's value during debugging.
  • type()ALT + T Wraps the word under the cursor in a Python type() function and executes it to reveal the object's class or data type in the output.
  • Echo executed command If enabled, prints the exact code snippet being executed into the output console before displaying its result, which is extremely helpful for providing context to output logs.
  • Execute allALT + RETURN Runs the entire script present in the current active tab from top to bottom.
  • Execute lineCTRL + SHIFT + RETURN Runs only the specific single line of code where the text cursor is currently positioned.
  • Execute selectedCTRL + RETURN Runs only the block of code that is currently highlighted/selected by the user.

Options Menu

  • Always on top Pins the editor window so it remains visible above all other application windows. This is particularly useful when referencing code while interacting with another application like Maya or Nuke.
  • AutocompleteALT + A Toggles the primary autocompletion engine, providing intelligent code suggestions as you type. Font styling and size are synced directly with the editor's settings.
  • Fuzzy autocomplete Enables a more flexible, fuzzy-matching algorithm for autocompletion, allowing you to find suggestions even if you skip characters or make minor typos.
  • Show docstrings Toggles the display of contextual documentation (docstrings) in a popup window alongside the autocomplete suggestions, providing immediate usage information. The docstring font is synchronized with the editor, and its text is fully selectable for copying.
  • Syntax check Toggles real-time background syntax checking. When enabled, the editor highlights Python syntax errors as you type, helping catch mistakes early.
  • Auto-close delimiters Toggles automatic closing of brackets, braces, parentheses, and quotes as you type in the editor.
  • Quick tab switching Toggles quick tab switching. When checked, you can press Ctrl+1 through Ctrl+9 to switch directly to tabs 1 through 9 (with temporary index numbers displayed on tab headers when holding the Ctrl key). It also enables Ctrl+Tab to cycle through open tabs via a popup list ordered by most recently used (MRU) tabs.
  • Choose font... Opens a system font selection dialog, allowing you to change the typeface, size, and weight of the text in the code editor globally.
  • Open settings folder Opens your operating system's file explorer directly to the directory where Multi Script Editor stores its configuration files, custom themes, user preferences, and session data.
  • Theme A sub-menu allowing you to apply different pre-installed color themes or open the advanced Theme Editor (Edit...) to heavily customize the syntax highlighting and UI colors.

  • GitHub Opens the official Multi Script Editor repository on GitHub in your default web browser for checking updates, reporting issues, or contributing.

  • Shortcuts Displays a comprehensive list of all keyboard shortcuts available in the editor to help you boost your coding productivity.
  • Documentation Opens this documentation file (mse.html) within your browser.
  • Help Shows general application help and tips.
  • About Displays the application version, author credits, and license information.

Code Theme Editor

The Code Theme Editor is an advanced tool designed to let you customize the visual experience of Multi Script Editor. It is accessed by going to Options -> Theme -> Edit....

Key Capabilities & Features:

  • Interactive Color Customization: The editor lists all customizable syntax elements (e.g., backgrounds, keywords, strings, comments, numbers, brackets, function names). Double-clicking any item opens a color picker dialog. Right-clicking an item displays a context menu allowing you to copy/paste colors or edit values directly. Newly added customizable colors include line_num_text (for the line number bar text), status_bar_text (for the status bar text), and bookmark (for the gutter bookmark ribbon/tag color).
  • Typography & Font Customization per Theme: You can define a custom font specifically for your theme. Clicking Choose Font... opens a dialog to select the font family, style, weight, and size. You can reset a custom font back to the application's global default by right-clicking the button and choosing "Reset to default".
  • Granular Interface Text Sizing: Customize text sizes independently for different parts of the user interface:
    • Text size: Adjusts the text size inside the code editor.
    • Line numbers: Adjusts the text size of the line number bar.
    • Menu text size: Adjusts the text size of all menus.
    • Tab labels: Adjusts the text size of the tab labels.
    • Symbols: Adjusts the text size of symbols in the symbol search/navigation helper.
    • Outline text size: Adjusts the text size of the code outline sidebar.
    • Output text size: Adjusts the text size of the console output window.
    • Status bar text size: Adjusts the text size inside the status bar.
  • Theme Font Inheritance Checkboxes: Checkboxes allow you to decide which UI areas should inherit the custom theme font instead of using default application styles:
    • Use theme font on completer
    • Use theme font on menus
    • Use theme font on outline
    • Use theme font on symbols
    • Use theme font on status bar
    • Use theme font on tab labels
  • Custom Layout Tweaks: Modify the Tab radius slider to adjust the corner roundness of the editor tabs, aligning them with your preferred styling.
  • Live Real-time Preview: A built-in interactive preview window displays a mock-up of the editor, including a Menu Bar (with File and Edit menus), active/inactive tabs containing code snippets, and a Status Bar. Any change made to colors, sizes, or fonts is rendered immediately in this preview before you commit to them.
  • Theme Import and Export: Save new themes or delete user-defined themes. Use the Import and Export buttons to backup your custom configurations or share them across different machines and environments.
