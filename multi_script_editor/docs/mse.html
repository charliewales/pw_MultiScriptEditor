Multi Script Editor Documentation

Multi Script Editor is an open-source, cross-platform, and cross-application code editor. It can be run as a standalone application or embedded within host software applications (such as Houdini, Maya, and Nuke), offering the ability to edit and execute code efficiently while automatically adapting to the host application's environment. While optimized for Python, it supports syntax highlighting, file parsing, and outline navigation for a wide range of CGI and web file formats.

Note

When running embedded inside DCC host applications, Multi Script Editor automatically links into the host's Python engine and environment variables, allowing live inspection and script execution directly inside your active scene session.

Key Features

  • Workspace Preservation: Restores tab order, file paths, unsaved text, modified state, cursor and scroll positions, bookmarks, folding state, splitter sizes, and visible panels.
  • Python Execution: Executes a selection, the current logical line, or the complete document in the standalone or active DCC namespace. Execution actions are disabled for non-Python files.
  • Completion and Validation: Bundled Jedi/Parso completion, fuzzy matching, docstring tooltips, live syntax checking, and contextual completion from the active Houdini, Maya, or Nuke runtime.
  • File Explorer: Direct path navigation, supported-file filtering, directory favorites, tab synchronization, multi-selection, file/folder operations, and external comparison.
  • Outline and Breadcrumbs: Searchable symbols, cursor following, alphabetical or source ordering, directory navigation, active scope tracking, and keyboard-operated popups.
  • Quick Navigation: Command Palette, recent files, open tabs, go to line, go to symbol, bookmark finder, and searchable snippets.
  • Editing Tools: Multi-cursor editing, occurrence selection, line movement, folding, bookmarks, smart Home behavior, delimiter pairing, comment toggling, quote/f-string helpers, and whitespace conversion.
  • Git and Diff: Optional status badges, branch information, diff, stage, unstage, commit, history, discard, repository-relative paths, and external file/folder comparison.
  • Output Workflow: Searchable output, occurrence highlighting, selection-to-tab, full-output-to-tab, save-to-file, clearing, wrapping, and configurable placement.
  • Sessions, Snippets, and Clipboard: Automatic and named sessions, recoverable backups, importable snippets, protected defaults, and persistent clipboard history.
  • Supported Files: Python, Bash, Batch, CSS, HTML, INI, JavaScript, JSON, Log, Markdown, Text, USD, XML, and YAML.
  • Themes and Layout: Custom syntax/UI themes, typography controls, menus and toolbar toggles, status tips, configurable sidebars, and output orientation.

Explorer, Outline & Breadcrumbs

File Explorer

The Explorer shares the left sidebar with Outline and can be toggled with CTRL + ALT + E. Its path field accepts a directory to set as root or a file path to open and reveal. The controls beside it navigate to the parent directory, synchronize once to the active tab, toggle automatic tab synchronization, filter to supported file types, add the current directory to favorites, and open the favorites menu.

Tree navigation
Double-click or middle-click a file to open it. A directory can become the Explorer root, while favorite directories provide persistent quick roots. File colors identify common code, data, documentation, web, shell, and USD formats.
Single-item context menu
Provides Copy file path, Open in editor, Set as explorer root [MMB], Add to favorites/bookmarks, Reveal in file explorer, New file..., New folder..., Delete (move to trash), and Rename.... The star control also exposes Bookmark current directory.
Multi-selection context menu
Opens all selected files, compares exactly two files or two folders, uses Copy selected full paths for every item, or moves the selected files and folders to trash.

Outline

The Outline tab parses the active document and filters symbols as you type. It supports collapse all, expand all, alphabetical/source-order sorting, and optional cursor following. Selecting an item jumps to its source line. Supported structures include Python classes, methods, functions, assignments, and imports; HTML/XML elements; Markdown headings; JSON/YAML/INI data; and USD primitives.

Breadcrumbs

Breadcrumbs display the full directory chain, active file, enclosing symbol chain, and current-scope contents. Directory and file popups reuse the Explorer tree and supported-file filter; symbol popups provide text filtering, arrow/Page/Home/End navigation, Enter selection, and Escape dismissal. The active symbol updates as the cursor moves.

Git & Comparison

Git support is opt-in through Options » Version control (GIT) or CTRL + ALT + G. It requires the git executable and a saved file inside a repository. When enabled, the active branch and file state appear in the status bar and modified tabs display compact Git status badges.

Git action popupCTRL + SHIFT + G
Searches the valid Git operations for the active file. The same operations are available from editor and tab context menus and from the Command Palette.
Stage, unstage, commit, and history
Stage File and Unstage File change the index state, Commit File... commits the active file through a themed dialog, and File History / Log... displays its commit log.
Diff and discard
Git Diff (vs HEAD) compares the working file with its HEAD revision using the configured diff tool. Discard Changes... requires confirmation, restores the Git version, reloads the tab, and cannot be undone.
External comparisonCTRL + ALT + SHIFT + C
Compares two files or two folders independently of Git. Choose another saved tab, browse from disk, or configure a discovered diff application.

Editor & Output Context Menus

Both text areas retain their standard Qt editing actions and add Multi Script Editor workflows. All added entries use the active theme and show status-bar descriptions when status tips are enabled.

Editor selection
Selection to tab copies selected editor text to a new tab. For a saved Markdown file, Markdown Preview opens the rendered overlay; for HTML, Open in browser launches the system browser.
Open in browser / Markdown PreviewCTRL + ALT + SHIFT + B
Uses the active saved file type to open HTML externally or render Markdown inside the editor. The action remains available even with no text selection.
Editor Git submenu
Appears at the top for saved repository files when Git is enabled and mirrors the file-level Git operations documented above.
Output actions
Selection to tab copies only selected console text. Output to tab copies the complete output, and Save output to... writes it to disk. Standard copy, select-all, and clear behavior remains available.

Host Integrations

multi_script_editor.show() detects Houdini, Maya, or Nuke and executes Python in that application's live namespace. Standalone mode uses its own persistent namespace. Host completion is sourced from the live DCC modules rather than bundled copies.

Houdini

  • Completes node types for createNode, createInputNode, and createOutputNode, plus quoted node paths, children, parameters, and parameter tuples.
  • Alt-modified node or parameter drops generate hou.node, hou.parm, or hou.parmTuple expressions.
  • Read From Node and Save To Node transfer Python SOP parameters or Python-capable HDA sections. Read from hou.session Sourse and Save to hou.session transfer the hou.session module source.

Maya

  • Completes Maya node types for cmds.createNode/pm.createNode and scene nodes for PyNode.
  • Alt-modified node drops generate PyMEL PyNode expressions when PyMEL is active or quoted node names for maya.cmds.
  • Save to shelf creates a Python button on the current shelf using the active tab and a selectable Maya icon. Floating and dock-control launch modes are supported.

Nuke

  • Completes node classes for createNode, allNodes, and selectedNodes; live node names for toNode; and knob names in node-index expressions.
  • Read PyScript Knob and Save To PyScript Knob transfer PyScript_Knob/PythonCustomKnob code. From Selected converts selected nodes to nuke.toNode(...), while From Clipboard extracts node names from copied Nuke script text.
  • Floating-window and registered-panel launch modes are supported.

Settings, Sessions & Status

Preferences are stored in an mse_settings directory under the current host's user-preference location. Options » Open settings folder opens the exact directory. Existing legacy preference files and named-session folders are migrated there when possible.

Automatic session and backup
Autosave tracks tab order, disk paths, untitled or modified text, cursor/scroll positions, bookmarks, folding, active tab, splitters, panels, and layout options. Unchanged backups are skipped.
Named sessions
Save a reusable workspace, restore the automatic backup, load a named session, or delete a named session. Overwriting an existing name requires confirmation.
Snippets and clipboard history
User snippets can be saved, imported, exported, inserted with Return, or executed with Enter/Numpad Enter; built-in snippets cannot be deleted. Clipboard history persists separately and is searchable.
Status bar
Reports cursor position, selection or occurrence count, total lines, language, word-wrap state, temporary status tips, and—when enabled—Git branch and file status.
Editor toolbar
Provides icon access to file comparison, output export, tab closing, bookmarks, search/navigation, formatting, multi-cursor actions, completion, folding, and zoom. It can be hidden without disabling its window-level shortcuts.

Code Theme Editor

Access the Theme Editor via Theme » Edit... (CTRL + SHIFT + T). It provides comprehensive real-time customization of UI colors, syntax tokens, font families, and element text sizes.

Tip

The Theme Editor includes a real-time live preview window showing a mock menu bar, code tabs, and status bar so you can see changes immediately before saving.

  • Interactive Color Palette: Double-click color items to open color picker, or right-click to copy/paste color codes. Supports line_num_text, status_bar_text, and bookmark gutter ribbon colors.
  • Typography & Font Inheritance: Define a custom font for your theme. Configurable checkboxes allow forcing theme font on completion popups, menus, outline, symbols, status bar, and tab labels.
  • Granular Interface Text Sizing: Independent text sliders for editor text, line numbers, menus, tab labels, symbols popup, outline sidebar, output panel, and status bar.
  • Layout Customization: Adjust tab corner radius and export/import theme JSON files.
