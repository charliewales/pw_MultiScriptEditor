Multi Script Editor Documentation

General Overview

Multi Script Editor is an open-source, cross-platform, and cross-application Python editor. It can be run as a standalone application or embedded within other software applications (such as Houdini, Nuke, Maya, 3DsMax), offering the ability to script in Python efficiently and centrally while automatically adapting to the host application's environment.

Key Features:

  • Preserves and loads tabs and the code within them automatically across sessions.
  • Interactive execution of selected code blocks or single lines.
  • Fully adjustable and customizable color themes for the code editor and UI.
  • Advanced code completion (powered by the jedi module).
  • Context-aware completion for different functions, such as existing nodes and scene paths depending on the integrated host software.
  • Built-in syntax checking and multi-cursor editing support.

Options by Menu

Below is a detailed breakdown of the different actions and tools grouped by the menu where they are located within the application:

File Menu

  • Open ScriptCTRL + O Opens an existing Python script file from your local filesystem, loading its contents into a new tab in the editor for editing and execution.
  • Save ScriptCTRL + S Saves the script in the currently active tab. If the script is new and hasn't been saved yet, it will prompt for a destination file path.
  • Save SessionCTRL + SHIFT + S Forces a save of the entire current session state. This includes all open tabs, their contents, and their specific order, ensuring they are automatically restored the next time the editor is launched.
  • Close All Tabs Closes all open tabs to reset your workspace, leaving only one empty tab. It prompts for confirmation to prevent accidental loss of unsaved snippets.
  • QuitCTRL + Q Closes the application safely. It ensures that the current session state is preserved before exiting.

Edit Menu (Tools)

  • UndoCTRL + Z Reverts the last text editing action in the active script, allowing you to step backward through your recent changes.
  • RedoCTRL + Y Re-applies the last undone action, allowing you to step forward through changes you previously undid.
  • CopyCTRL + C Copies the currently selected text to the system clipboard for pasting elsewhere.
  • CutCTRL + X Removes the currently selected text from the document and places it into the system clipboard.
  • PasteCTRL + V Inserts the current content of the system clipboard at the cursor's location.
  • Delete LineCTRL + D Immediately deletes the entire line where the text cursor is currently located, without the need to select the whole line first.
  • Duplicate LineCTRL + SHIFT + D Duplicates the current line (if no text is selected) or the currently selected text block, inserting it immediately below the original.
  • Move Line(s) UpALT + UP Shifts the currently selected line(s) or the line at the cursor one position upwards in the document.
  • Move Line(s) DownALT + DOWN Shifts the currently selected line(s) or the line at the cursor one position downwards in the document.
  • Add QuotesALT + Q Wraps the currently selected text with quotation marks. Very useful for quickly converting variables or text into string literals.
  • CommentALT + C Toggles the Python comment state (using #) for the current line or selected block of lines, allowing you to quickly comment out or uncomment code blocks.
  • Select Next OccurrenceCTRL + ALT + D Finds and selects the next instance of the currently selected word (or the word under the cursor), enabling multi-cursor editing for rapid refactoring.
  • Select All OccurrencesCTRL + SHIFT + ALT + D Selects every instance of the current word throughout the entire document, placing a cursor at each instance for simultaneous editing.
  • Find and ReplaceCTRL + F Opens the search tool panel to find specific text strings and optionally replace them with new text. It supports case sensitivity and regular expressions.
  • Go to LineCTRL + G Prompts for a line number and moves the cursor to that specific line in the editor.
  • Tab to spaces Converts all tab characters in the current document to standard space characters (typically 4 spaces) to ensure PEP 8 compliance and avoid indentation errors.
  • Render WhitespaceCTRL + SHIFT + W Toggles the visibility of whitespace characters (spaces as dots, tabs as arrows) in the editor to aid in formatting and detecting trailing spaces.
  • Word WrapALT + W Toggles automatic wrapping of long lines of code so they visually fit within the editor's width without requiring horizontal scrolling.
  • Word Wrap (Output)CTRL + ALT + W Toggles word wrap specifically for the output console panel, preventing horizontal scrolling for long print outputs.

Run Menu

  • Clear Output before ExecutionCTRL + ALT + C When enabled, the application automatically clears the console output panel every time you run a script, keeping the output focused exclusively on the latest execution results.
  • Clear OutputCTRL + SHIFT + C Manually clears all text currently displayed in the output console panel.
  • dir()ALT + D Wraps the word under the cursor with the Python dir() function and executes it. This prints all valid attributes and methods of the selected object in the output console.
  • help()ALT + H Wraps the word under the cursor with the Python help() function and executes it, displaying Python's built-in documentation for that specific object or function.
  • print() Wraps the word under the cursor in a print() statement, making it easy to quickly output a variable's value during debugging.
  • type()ALT + T Wraps the word under the cursor in a Python type() function and executes it to reveal the object's class or data type in the output.
  • Echo Executed CommandALT + E If enabled, prints the exact code snippet being executed into the output console before displaying its result, which is extremely helpful for providing context to output logs.
  • Execute AllALT + ENTER Runs the entire script present in the current active tab from top to bottom.
  • Execute LineCTRL + ALT + ENTER Runs only the specific single line of code where the text cursor is currently positioned.
  • Execute SelectedCTRL + ENTER Runs only the block of code that is currently highlighted/selected by the user.

Options Menu

  • AutocompleteALT + A Toggles the primary autocompletion engine, providing intelligent code suggestions as you type.
  • Fuzzy Autocomplete Enables a more flexible, fuzzy-matching algorithm for autocompletion, allowing you to find suggestions even if you skip characters or make minor typos.
  • Show Docstrings Toggles the display of contextual documentation (docstrings) in a popup window alongside the autocomplete suggestions, providing immediate usage information.
  • Show OutlineCTRL + SHIFT + O Toggles the visibility of the code outline sidebar. This panel provides a structural overview of the script (showing classes, methods, and functions) for rapid navigation.
  • Syntax Check Toggles real-time background syntax checking. When enabled, the editor highlights Python syntax errors as you type, helping catch mistakes early.
  • Always on topCTRL + ALT + T Pins the editor window so it remains visible above all other application windows. This is particularly useful when referencing code while interacting with another application like Maya or Nuke.
  • Choose Font... Opens a system font selection dialog, allowing you to change the typeface, size, and weight of the text in the code editor to suit your visual preferences.
  • Open Settings Folder Opens your operating system's file explorer directly to the directory where Multi Script Editor stores its configuration files, custom themes, user preferences, and session data.
  • Theme A sub-menu allowing you to apply different pre-installed color themes or open the advanced Theme Editor (Edit...) to heavily customize the syntax highlighting and UI colors down to individual elements.

Help Menu

  • Quick HelpF1 Shows a quick reference guide overlay detailing the most common features and available host-specific environment variables.
  • GitHub Opens the official Multi Script Editor repository on GitHub in your default web browser for checking updates, reporting issues, or contributing.
  • Houdini Env Variables Opens external web documentation specific to Houdini's environment variables.
  • Houdini hou package Opens external web documentation for the Houdini hou Python module.
  • Maya Commands Opens external web documentation for Autodesk Maya's Python commands (maya.cmds).
  • Nuke Dev Guide Opens the official Nuke Python developer guide.
  • Qt for Python Opens official documentation for Qt for Python (PySide), which is vital when building custom UIs within the editor.
  • Qt Modules Opens the reference documentation for individual Qt modules.
  • Python documentation Opens the official Python documentation online for the version currently being used by the editor.
  • Shortcuts Displays a comprehensive list of all keyboard shortcuts available in the editor to help you boost your coding productivity.
  • Documentation Opens this exact documentation file within your browser.
  • Help Shows general application help and tips.
  • About Displays the application version, author credits, and license information.
